# Our Connected Worlds

Our Connected Worlds is a game aggregator connecting independent games through a shared progression system.

Players travel between worlds created by other creators, obtain resources, earn currency and develop their own personal world.

Creators define their own gameplay, economy and rewards while benefiting from a shared ecosystem of players, items and progression, all optional.

## Core Pillars

- Shared character progression
- Shared item ecosystem
- Shared economy balancing
- Independent game worlds
- Safe execution through sandboxed environments
