# Visual Architecture

The project will be explained through five core diagrams.

## D1 - Player Journey

**Purpose**

Explain how a player progresses through the ecosystem.

**Diagram**

```text
Personal World
      ↓
Visit World
      ↓
Play
      ↓
Earn Resources
      ↓
Import Resources
      ↓
Improve Personal World
```

**Question answered**

> Why would a player use the aggregator?

---

## D2 - Creator Journey

**Purpose**

Explain why creators benefit from participating.

**Diagram**

```text
Create World
      ↓
Publish World
      ↓
Players Visit
      ↓
Creator Earns Currency
      ↓
Improve World
      ↓
More Players
```

**Question answered**

> Why would a creator join the platform?

---

## D3 - Shared Item Ecosystem

**Purpose**

Explain how resources move between worlds.

**Diagram**

```text
World A
     ↓
Player Obtains Item
     ↓
Aggregator Account
     ↓
World B
```

**Question answered**

> What makes worlds connected?

This is one of the most important diagrams of the project.

---

## D4 - Moderation Workflow

**Purpose**

Explain how worlds become trusted.

**Diagram**

```text
Publish World
      ↓
Trial Period
      ↓
Player Judgement
      ↓
Consensus
      ↓
Approved
```

**Alternative path**

```text
Report
      ↓
Investigation
      ↓
Suspension
```

**Question answered**

> How does the platform protect itself from abuse?

---

## D5 - Technical Architecture

**Purpose**

Explain how games remain isolated.

**Diagram**

```text
Aggregator
      ↓
Launch Container
      ↓
Run Game
      ↓
Produce Reward JSON
      ↓
Aggregator Validation
      ↓
Apply Rewards
```

**Question answered**

> How can user-created games be executed safely?

---

## Diagram Priority

Priority order:

1. Shared Item Ecosystem
2. Player Journey
3. Creator Journey
4. Technical Architecture
5. Moderation Workflow

**Reason**

The shared item ecosystem is the unique selling point of the project. It should be explained first in most presentations.
